题目二

题目二n范围为0≤n≤1000，枚举法不可行，需要使用更高效的算法。

这里使用的了Johnson算法，时间复杂度为O(n log n)

Johnson算法介绍

问题背景

有 n 个作业（顾客 / 产品）集合 J = {1,2,…,n}。每个作业 i 必须先在机器 1（记作 M1）加工 a_i 时间，然后在机器 2（M2）加工 b_i 时间；同一机器同一时刻至多加工一个作业；作业在 M2 上的加工只能在其在 M1 上完成后才能开始（不能等待负时间）。我们要找一个排列（序列）σ，使得所有作业完成（即各自第二道工序结束）的最晚时间 C_max(σ) 最小。

设：

M1 上按序列 σ 依次无间断处理：其开始/结束时间由前缀 a 求和决定；
M2 不能抢占，且作业 i 的第二阶段最早开始时间是 max( M2 上上一作业完成时间, 该作业在 M1 上完成时间 )。
目标：Minimize C_max = 完成时间最大值（即 M2 完成最后一个作业的时间）。

Johnson Rule

等价表述 A（“分组 + 排序”）：

  1. 令 S1 = { i | a_i ≤ b_i } ，S2 = { i | a_i > b_i }。
  2. 在 S1 内按 a_i 升序排序。
  3. 在 S2 内按 b_i 降序排序。
  4. 最终序列：S1 的排序结果接上 S2 的排序结果。

等价表述 B（“逐步选择 + 双端填充”）： 重复直到所有作业被放入序列：

  1. 在尚未安排的作业集合中求最小值 m = min{ a_k, b_k }。
  2. 若 m 来自某作业 i 的 a_i（即 a_i ≤ b_i），则把作业 i 放到当前序列“最左端”尚空的位置；
  3. 若 m 来自某作业 j 的 b_j（即 a_j > b_j），则把作业 j 放到当前序列“最右端”尚空的位置；
  4. 删除该作业，继续。
    这两种表述等价；表述 B 更揭示“最小值放端点”的构造思想，表述 A 实现更直接。

算法步骤

  1. 将所有作业分为两类：
    • 第一类：在 M1 上的加工时间小于在 M2 上的加工时间的作业（a_i < b_i）。
    • 第二类：在 M1 上的加工时间大于或等于在 M2 上的加工时间的作业（a_i ≥ b_i）。
  2. 对第一类作业，按其在 M1 上的加工时间 a_i 从小到大排序。
  3. 对第二类作业，按其在 M2 上的加工时间 b_i 从大到小排序。
  4. 将第一类作业按排序后的顺序放在前面，第二类作业按排序后的
  5. 我们就得到了一个满足条件的序列 σ。
  6. 计算 C_max(σ)：
    • 初始化 M1 和 M2 的完成时间 t1 = 0, t2 = 0。
    • 对于序列 σ 中的每个作业 i：
      • 更新 M1 的完成时间：t1 += a_i。
      • 更新 M2 的完成时间：t2 = max(t2, t1) + b_i。
    • 最终的 C_max(σ) 即为 t2。

算法正确性

Johnson算法的正确性可以通过交换论证来证明。假设存在一个最优序列 σ’，使得 C_max(σ’) < C_max(σ)。

首先，根据算法步骤 1 和 2，我们可以将作业分为两类：

  • 第一类：在 M1 上的加工时间小于在 M2 上的加工时间的作业。
  • 第二类：在 M1 上的加工时间大于或等于在 M2 上的加工时间的作业。

假设 σ’ 的第一类作业集合为 J1，第二类作业集合为 J2。

  • 假设 J1 中存在作业 i，使得 a_i < b_i，并且 σ’ 中存在作业 j，使得 j 在 J1 中，并且 j 在 J2 中。
  • 假设 J2 中存在作业 j，使得 b_j < a_j，并且 σ’ 中存在作业 i，使得 i 在 J1 中，并且 i 在 J2 中。

根据算法步骤 3 和 4，我们可以得到：

  • 对于 J1 中的作业 i，σ’ 中存在作业 j，使得 j 在 J1 中，并且 j 在 J2 中，并且 a_j < b_j。
  • 对于 J2 中的作业 j，σ’ 中存在作业 i，使得 i 在 J1 中，并且 i 在 J2 中，并且 b_i < a_i。

因此，我们可以得到：

  • C_max(σ’) < C_max(σ)。

因此，Johnson算法的正确性得以证明。
